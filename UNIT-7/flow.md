# **Self-Regulation – Quick Revision Notes**

_UGC-NET Psychology | Unit 7_

## **1. Core Definition**

**Self-regulation:** Monitoring, evaluating and modifying one's thoughts, emotions and behaviour to achieve personal goals.

## **2. Major Theorists and Models**

| Theorist                      | Theory / Model                   | Key NET Points                            |
| ----------------------------- | -------------------------------- | ----------------------------------------- |
| Albert Bandura (1986, 1991)   | Social Cognitive Self-Regulation | Self-observation, judgment, self-reaction |

## **3. Important Models**

**A. Bandura – Social Cognitive Model**

1. Self-observation – Monitoring behaviour.
2. Judgment – Comparing behaviour with standards.
3. Self-reaction – Self-reinforcement or self-punishment.

**B. Carver and Scheier – Control Theory**

Based on TOTE by Miller, Galanter and Pribram (1960).

- Test → Operate → Test → Exit.
- Negative feedback reduces the discrepancy between current performance and the goal.

**Sequence:** Input → Comparison with standard → Output/action → Feedback.

**C. Baumeister – Strength Model**

- Self-control operates like a limited resource.
- **Ego depletion:** Previous self-control exertion may impair subsequent self-control.
- Four ingredients: Standards, monitoring, strength and motivation.

**D. Zimmerman – Self-Regulated Learning**

| Phase           | Components                                         |
| --------------- | -------------------------------------------------- |
| Forethought     | Goal setting, planning, self-efficacy              |
| Performance     | Self-control, attention focusing, self-observation |
| Self-reflection | Self-evaluation, attribution, self-reaction        |

**E. Mischel – Hot and Cool Systems**

- **Hot:** Emotional, impulsive, immediate gratification.
- **Cool:** Cognitive, reflective, delayed gratification.
- Associated with the Stanford Marshmallow Experiment.

**F. Kanfer – Behavioural Self-Regulation**

1. Self-monitoring
2. Self-evaluation
3. Self-reinforcement

**G. Higgins – Regulatory Focus Theory (1997)**

| Promotion Focus        | Prevention Focus          |
| ---------------------- | ------------------------- |
| Ideal self             | Ought self                |
| Growth and advancement | Safety and responsibility |
| Focus on gains         | Focus on avoiding losses  |
| Eager strategies       | Vigilant strategies       |

## **4. Self-Regulation vs. Self-Control**

| Self-Regulation                  | Self-Control                               |
| -------------------------------- | ------------------------------------------ |
| Broad process                    | Specific component                         |
| Goal setting and monitoring      | Impulse inhibition                         |
| Initiates and modifies behaviour | Resists immediate temptation               |
| Continuous regulation            | Often involves resisting an immediate urge |

## **5. Important Related Concepts**

- **Under-regulation:** Failure to exercise sufficient control.
- **Misregulation:** Using control strategies counterproductively.
- **Ironic Process Theory – Daniel Wegner (1994):** Thought suppression can produce a rebound effect.
- **Process Model – Michael Inzlicht:** Self-control failure may involve motivational and attentional shifts rather than simply depleted resources.

## **6. Neurobiological Basis**

## **Most Important for NET**

- **Bandura:** Observation → Judgment → Reaction.
- **Kanfer:** Monitoring → Evaluation → Reinforcement.
- **Zimmerman:** Forethought → Performance → Self-reflection.
- **TOTE:** Test → Operate → Test → Exit.
- **Higgins:** Promotion = Ideal; Prevention = Ought.

**MCQ caution:** Baumeister proposed the Strength Model of Ego Depletion. Inzlicht's Process Model provides an alternative explanation based on changes in motivation and attention.
