## **1. Introduction & Background**

- **Endel Tulving (1927–2023):** Estonian-Canadian cognitive psychologist, widely recognised for his contributions to the study of human memory.
- **Major contribution:** Distinguished **episodic memory and semantic memory** in 1972.
- He challenged the traditional assumption that long-term memory functions as a single, unitary system.
- Later contributions included the **Encoding Specificity Principle (1973)** and the relationship between memory systems and consciousness.

### **Key publications**

| Year | Publication / Contribution                                                                 |
| ---- | ------------------------------------------------------------------------------------------ |
| 1972 | _Episodic and Semantic Memory_                                                             |
| 1973 | _Encoding Specificity and Retrieval Processes in Episodic Memory_ (with Donald M. Thomson) |
| 1983 | _Elements of Episodic Memory_                                                              |
| 1985 | Further development of the relationship between memory and consciousness                   |

**NET association:** Tulving (1972) = Episodic-Semantic distinction; Tulving and Thomson (1973) = Encoding Specificity Principle.

## **2. Core Philosophy — Memory Is Not Unitary**

Tulving proposed that human memory consists of **multiple, functionally distinct but interacting systems**.

### **Key propositions**

1. **Multiple memory systems:** Long-term memory contains different systems, including episodic, semantic and procedural memory.
2. **Different functions:** Each system performs different memory-related functions.
3. **Consciousness:** Memory systems are associated with different forms of conscious awareness.
4. **Interaction:** Memory systems are distinct but interact during normal cognitive functioning.

**NET trap:** Tulving challenged the idea of a single, unitary long-term memory system.

## **3. Episodic vs. Semantic Memory (1972)**

This is Tulving's most important contribution and a highly significant NET topic.

### **A. Episodic Memory**

- Memory for **personally experienced events and experiences**.
- Includes information about when and where an event occurred.
- Involves autobiographical reference to the self.
- Allows individuals to mentally revisit past experiences.
- Also supports imagining possible future experiences.

**Examples:**

- Remembering your first day at university.
- Recalling what you ate yesterday.
- Remembering a particular birthday celebration.

**Key term:** Autonoetic consciousness.

### **B. Semantic Memory**

- Memory for general knowledge, facts, concepts and meanings.
- Does not require recollection of the particular occasion on which information was learned.
- Organised knowledge about the world.
- Tulving described it as a kind of **mental thesaurus**.

**Examples:**

- Knowing that New Delhi is the capital of India.
- Knowing that water is composed of hydrogen and oxygen.
- Knowing the meaning of a psychological concept.

**Key term:** Noetic consciousness.

### **Comparison: Episodic vs. Semantic Memory**

| Dimension         | Episodic Memory                 | Semantic Memory           |
| ----------------- | ------------------------------- | ------------------------- |
| Nature            | Personal experiences            | General knowledge         |
| Reference         | Autobiographical                | Conceptual                |
| Time and place    | Important                       | Not necessarily relevant  |
| Consciousness     | Autonoetic                      | Noetic                    |
| Example           | Remembering yesterday's lecture | Knowing what a lecture is |
| Mental experience | Reliving an event               | Knowing a fact            |

High-yield NET distinction

**Remember:** Episodic = Remembering an experience; Semantic = Knowing information.

## **4. Encoding Specificity Principle (1973)**

Proposed by **Endel Tulving and Donald M. Thomson (1973)**.

### **Definition**

The Encoding Specificity Principle states that the effectiveness of retrieval cues depends on how well they match the information and conditions established during encoding.

In simple terms:

**Memory retrieval is more effective when the retrieval cue matches the way information was originally encoded.**

### **Key propositions**

1. Encoding determines what information becomes available in memory.
2. Retrieval cues are effective when they match the encoded information.
3. A cue that appears unrelated may still be effective if it was associated with the information during encoding.
4. Retrieval depends on the relationship between encoding and retrieval conditions.

### **Example**

Imagine studying the word _river_ while associating it with the word _water_.

Later, when asked to recall the word, the cue _water_ may help you retrieve _river_.

The cue is effective because of its association during encoding.

### **Recognition Failure of Recallable Words**

- Demonstrated by Tulving and Thomson (1973).
- Participants could sometimes recall words when given appropriate cues but failed to recognise those same words in a recognition test.
- This challenged simple explanations that assume recognition must always be easier than recall.
- It supported the importance of encoding-specific retrieval cues.

**NET association:** Tulving and Thomson (1973) = Encoding Specificity + Recognition Failure of Recallable Words.

## **5. Multiple Memory Systems and Types of Consciousness**

Tulving associated different memory systems with three forms of consciousness.

| Memory System  | Consciousness  | Meaning                                                     |
| -------------- | -------------- | ----------------------------------------------------------- |
| **Procedural** | **Anoetic**    | Non-knowing; performance without conscious recollection     |
| **Semantic**   | **Noetic**     | Knowing facts and information                               |
| **Episodic**   | **Autonoetic** | Self-knowing; conscious recollection and mental time travel |

### **A. Anoetic Consciousness**

- Associated with procedural memory.
- Involves responding or performing without conscious recollection of the learning experience.
- Example: Riding a bicycle without consciously recalling each step involved.

### **B. Noetic Consciousness**

- Associated with semantic memory.
- Involves awareness of facts and knowledge.
- Example: Knowing that Paris is the capital of France without remembering when you learned it.

### **C. Autonoetic Consciousness**

- Associated with episodic memory.
- Involves awareness of oneself across subjective time.
- Allows mental time travel into the past and imagination of possible future experiences.

**Example:** Remembering your previous birthday and imagining how you might celebrate the next one.

**Tulving's Memory–Consciousness Associations**

**Procedural Memory**

ANOETIC — Non-knowing

**Semantic Memory**

NOETIC — Knowing

**Episodic Memory**

AUTONOETIC — Self-knowing

**NET memory trick:**

- A = Anoetic = Action without conscious recollection.
- N = Noetic = Knowing.
- A = Autonoetic = Awareness of oneself in time.

## **6. Remember/Know Paradigm**

Tulving introduced the **Remember/Know distinction** to examine the subjective experience of remembering.

It distinguishes between two kinds of recognition experience:

| Remember                                          | Know                                        |
| ------------------------------------------------- | ------------------------------------------- |
| Conscious recollection of the learning experience | Feeling of familiarity without recollection |
| Associated with episodic recollection             | Associated with familiarity                 |
| Includes contextual details                       | Lacks specific contextual details           |

**Example:**

- Remember: "I remember studying this word on the second page of my notes."
- Know: "This word looks familiar, but I cannot remember where I encountered it."

**NET trap:** Remember = Recollection; Know = Familiarity. Do not confuse this experimental distinction with the claim that all familiarity is simply semantic memory.

## **7. Patient K.C. and Mental Time Travel**

**Patient K.C. (Kent Cochrane)** was a famous neuropsychological case studied by Tulving and colleagues.

### **Major characteristics**

- K.C. experienced severe episodic memory impairment following a brain injury.
- He could not recollect specific autobiographical events from his past.
- However, aspects of his semantic knowledge remained relatively preserved.
- He also struggled to imagine and mentally experience specific personal future events.

### **Importance**

The case demonstrated a close relationship between episodic memory and the ability to mentally project oneself into the future.

**NET association:** Patient K.C. = Episodic amnesia + Impaired future thinking.

## **8. Comparison with Other Memory Theorists**

| Dimension          | Tulving                       | Atkinson & Shiffrin | Baddeley & Hitch               | Craik & Lockhart            |

| Main theory        | Multiple memory systems       | Multi-Store Model   | Working Memory Model           | Levels of Processing        |
| Main focus         | Types of LTM                  | Memory stores       | Active short-term processing   | Depth of processing         |
| Major contribution | Episodic-semantic distinction | Sensory, STM, LTM   | Multi-component working memory | Shallow vs. deep processing |
| Key concept        | Autonoetic consciousness      | Rehearsal           | Central executive              | Semantic processing         |

**Important distinction:** Tulving classified long-term memory according to different systems and functions; Atkinson and Shiffrin proposed a structural model containing three major stores.

## **9. Contributions**

1. **Episodic-semantic distinction:** Established that remembering personal experiences differs from knowing general facts.
2. **Encoding specificity:** Demonstrated the importance of matching retrieval cues to encoding conditions.
3. **Multiple memory systems:** Advanced the understanding of memory as a collection of interacting systems.
4. **Consciousness and memory:** Connected memory systems with anoetic, noetic and autonoetic consciousness.
5. **Remember/Know paradigm:** Provided an important method for studying recollection and familiarity.
6. **Mental time travel:** Established the importance of episodic memory for remembering the past and imagining the future.

## **10. Criticisms**

1. **Overlap between systems:** Episodic and semantic memory are closely interconnected, making complete separation difficult.
2. **Difficulty measuring consciousness:** Anoetic, noetic and autonoetic consciousness are difficult to measure objectively.
3. **Subjective reporting:** Remember/Know judgments depend partly on participants' subjective experiences.
4. **Alternative explanations:** Some researchers argue that episodic and semantic memory may reflect different forms of processing within a broader memory system rather than completely separate systems.
5. **Classification limitations:** The boundaries between different memory systems are not always clear in real-life cognitive activities.
