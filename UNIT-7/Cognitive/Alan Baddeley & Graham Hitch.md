# **Alan Baddeley & Graham Hitch's Working Memory Model — Quick Revision Notes**

## **1. Introduction & Background**

- **Alan D. Baddeley (born 1934)** and **Graham J. Hitch (born 1946):** British cognitive psychologists who proposed the **Working Memory Model (WMM)** in 1974.
- **Key publication:** _Working Memory_ (1974), published in _The Psychology of Learning and Motivation_.
- The model challenged Atkinson and Shiffrin's idea of a single, unitary short-term memory store.
- It proposed that working memory is an **active, multi-component system** responsible for temporarily storing and manipulating information.
- **Baddeley (2000)** subsequently added a fourth component, the **episodic buffer**.

**NET association:** Baddeley and Hitch (1974) = Working Memory Model; Baddeley (2000) = Episodic Buffer.

## **2. Core Philosophy — Working Memory as Active Processing**

The central argument is that short-term memory does more than temporarily store information. It actively maintains and manipulates information during ongoing cognitive activities.

Examples:

- Performing mental arithmetic.
- Understanding complex sentences.
- Solving problems.
- Following directions.
- Reasoning and decision-making.

### **Key propositions**

1. **Multiple components:** Working memory consists of different subsystems rather than a single store.
2. **Active processing:** Information is temporarily stored and manipulated.
3. **Limited capacity:** Working memory has limited resources.
4. **Parallel processing:** Different subsystems can perform different tasks simultaneously.
5. **Dual-task evidence:** Two tasks using different components may be performed together with relatively little interference.

**NET trap:** Working memory is not simply another name for short-term memory. It emphasises active storage and manipulation.

## **3. Original Components of the Working Memory Model (1974)**

The original model contained three major components.

### **1. Central Executive**

- Acts as the **attentional control system**.
- Allocates and coordinates attention.
- Controls the activities of the phonological loop and visuospatial sketchpad.
- Prioritises tasks and coordinates cognitive activities.
- Has limited attentional capacity.
- Does not function as a dedicated storage system.

**Example:** Concentrating on solving a mathematical problem while ignoring irrelevant distractions.

**NET association:** Central Executive = Attentional control, coordination and resource allocation.

### **2. Phonological Loop**

- Processes and temporarily stores **verbal and auditory information**.
- Responsible for maintaining speech-based information.
- Contains two important subcomponents.

| Subcomponent                       | Function                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------- |
| **Phonological Store**             | Temporarily holds speech-based information; often described as an auditory memory trace. |
| **Articulatory Rehearsal Process** | Repeats information subvocally to refresh the memory trace.                              |

**Example:** Silently repeating a telephone number to remember it.

Important experimental effects associated with the phonological loop:

- **Phonological similarity effect:** Similar-sounding words are more difficult to remember in order.
- **Word-length effect:** Short words are generally recalled better than long words.
- **Articulatory suppression:** Repeating an irrelevant sound or word interferes with subvocal rehearsal.
- **Irrelevant speech effect:** Unattended speech can disrupt verbal short-term memory.

**NET association:** Phonological loop = Verbal/auditory information.

### **3. Visuospatial Sketchpad**

- Temporarily stores and manipulates **visual and spatial information**.
- Helps construct and maintain mental images.
- Supports spatial navigation and mental rotation.
- Operates separately from the phonological loop, although the components interact.

**Example:** Mentally visualising a route or remembering the arrangement of furniture in a room.

**NET association:** Visuospatial sketchpad = Visual imagery + Spatial information.

## **4. Episodic Buffer (Added in 2000)**

Baddeley introduced the episodic buffer to address limitations in the original model, particularly its difficulty explaining how information from different subsystems and long-term memory is integrated.

### **Definition**

The **episodic buffer** is a limited-capacity temporary storage system that integrates information from different sources into a unified, multidimensional representation.

### **Major functions**

1. **Multimodal integration:** Combines verbal, visual and spatial information.
2. **Binding:** Integrates different features into coherent episodes.
3. **LTM connection:** Provides an interface between working memory and long-term memory.
4. **Conscious representation:** Helps maintain integrated information available to conscious awareness.

**Example:** Remembering a conversation by combining the spoken words, the speaker's appearance and the surrounding situation.

**Updated Working Memory Model**

**Central Executive**

Attentional control and coordination

**Phonological Loop**

Verbal and auditory information

**Visuospatial Sketchpad**

Visual and spatial information

**Episodic Buffer (2000)**

Integrates information from subsystems and LTM

Conceptual illustration of the four components; the episodic buffer also interacts with the other components and long-term memory.

**NET association:** Episodic Buffer → Baddeley (2000) → Multimodal integration and connection with LTM.

## **5. Evidence Supporting the Working Memory Model**

### **A. Dual-Task Experiments**

- Participants perform two tasks simultaneously.
- When tasks use different working-memory components, interference is relatively low.
- When tasks compete for the same component, interference increases.

**Conclusion:** Working memory consists of relatively distinct subsystems rather than a single unitary store.

### **B. Phonological Similarity Effect**

- Participants find it difficult to recall sequences of similar-sounding words.
- This supports the existence of a specialised verbal storage system.

### **C. Word-Length Effect**

- Short words are generally easier to recall than long words.
- This supports the role of rehearsal and the limited capacity of the phonological loop.

### **D. Articulatory Suppression**

- Repeating an irrelevant sound interferes with subvocal rehearsal.
- This provides evidence for the articulatory rehearsal process.

**NET trap:** Dual-task experiments are particularly important evidence for the multi-component nature of working memory.

## **6. Comparison with Atkinson & Shiffrin's Multi-Store Model**

| Dimension        | Atkinson & Shiffrin (1968)             | Baddeley & Hitch (1974)                      |
| ---------------- | -------------------------------------- | -------------------------------------------- |
| Memory structure | Three structural stores                | Multiple interacting components              |
| STM              | Unitary store                          | Active working-memory system                 |
| Main function    | Temporary storage                      | Storage and manipulation                     |
| Capacity         | Traditionally 7 ± 2                    | Limited, component-specific resources        |
| Main mechanism   | Rehearsal and transfer                 | Attentional control and subsystem processing |
| Evidence         | Serial position and memory experiments | Dual-task experiments                        |
| Key contribution | Multi-Store Model                      | Working Memory Model                         |

**Remember:** Atkinson and Shiffrin = Unitary STM; Baddeley and Hitch = Multi-component working memory.

## **7. Contributions**

1. **Reconceptualised STM:** Replaced the idea of a passive, unitary store with an active processing system.
2. **Multi-component structure:** Identified specialised systems for verbal and visuospatial information.
3. **Central executive:** Highlighted the importance of attentional control in cognition.
4. **Episodic buffer:** Extended the model to explain multimodal integration and interaction with LTM.
5. **Applied significance:** Influenced research into learning, reading, language comprehension, reasoning and cognitive disorders.

## **8. Criticisms**

1. **Central executive is underspecified:** Its precise mechanisms and internal structure were initially not clearly explained.
2. **Limited explanation of long-term memory:** The original model did not adequately explain how working memory interacts with LTM.
3. **Component boundaries:** The separation between verbal and visuospatial processing may not always be clear-cut.
4. **Episodic buffer:** Although it explains integration, its precise mechanisms and capacity remain difficult to establish.
5. **Limited explanation of individual differences:** The original model does not fully explain all variations in working-memory performance.

## **10. Likely NET MCQ Traps**

- **Baddeley and Hitch (1974):** Working Memory Model.
- **Baddeley (2000):** Episodic buffer.
- **Central executive:** Controls attention; not a dedicated storage system.
- **Phonological loop:** Verbal and auditory information.
- **Visuospatial sketchpad:** Visual and spatial information.
- **Phonological store:** Temporary storage of speech-based information.
- **Articulatory rehearsal:** Subvocal repetition.
- **Episodic buffer:** Integrates information from different modalities and LTM.
- **Dual-task experiments:** Evidence for separate working-memory components.
- **Word-length effect:** Associated with the phonological loop.
- **Phonological similarity effect:** Associated with verbal short-term memory.
- **Atkinson and Shiffrin:** Multi-Store Model, not Working Memory Model.
