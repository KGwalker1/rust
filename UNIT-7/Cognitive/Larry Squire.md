# **Larry R. Squire's Memory Systems Theory — Quick Revision Notes**

**UGC-NET JRF Psychology | December 2026**

## **1. Introduction & Background**

- **Larry R. Squire (born 1941):** American neuroscientist and psychologist known for his contributions to the cognitive neuroscience of memory.
- His major contribution was distinguishing **declarative (explicit) memory** from **nondeclarative (implicit) memory** and relating these forms to different brain systems.
- His research demonstrated that memory is not a single faculty but consists of multiple systems with different functions and neural foundations.
- His work drew on evidence from human patients, monkeys and rats.

### **Key publications**

| Year | Publication / Contribution                                                             |
| ---- | -------------------------------------------------------------------------------------- |
| 1987 | _Memory and Brain_                                                                     |
| 1991 | Squire and Zola-Morgan's work on the medial temporal lobe memory system                |
| 1992 | _Memory and the hippocampus: A synthesis from findings with rats, monkeys, and humans_ |
| 1998 | _Memory: From Mind to Molecules_ (with Eric Kandel)                                    |

**NET association:** Larry Squire = Declarative vs. Nondeclarative Memory; Squire and Zola-Morgan = Medial Temporal Lobe Memory System.

## **2. Core Philosophy — Memory Consists of Multiple Systems**

Squire proposed that memory consists of several distinct but interacting systems, each supported by different neural structures.

### **Key propositions**

1. **Memory is heterogeneous:** Different forms of memory perform different functions.
2. **Declarative memory:** Supports conscious recollection of facts and events.
3. **Nondeclarative memory:** Supports learning expressed through performance without requiring conscious recollection.
4. **Different neural substrates:** Different memory systems depend on different brain structures.
5. **Dissociation:** Brain damage can impair one memory system while leaving another relatively intact.

**NET trap:** Declarative and nondeclarative memory are not simply two stages of memory. They are different memory systems.

## **3. Declarative vs. Nondeclarative Memory**

This is Squire's most important contribution and a high-priority NET topic.

### **A. Declarative Memory (Explicit Memory)**

- Involves conscious recollection of information.
- Includes facts, concepts and personally experienced events.
- Information can generally be consciously recalled and expressed verbally.
- Depends critically on the **medial temporal lobe memory system**, including the hippocampus and adjacent cortical regions.

**Two major forms:**

1. **Episodic memory:** Memory for personal experiences and events.
2. **Semantic memory:** Memory for facts, meanings and general knowledge.

**Examples:**

- Remembering your first day at university.
- Knowing the capital of India.
- Recalling a particular lecture.

### **B. Nondeclarative Memory (Implicit Memory)**

- Involves learning that does not require conscious recollection of the original learning experience.
- Often demonstrated through improved performance.
- Includes skills, habits, priming and conditioning.
- Depends on several neural systems outside the medial temporal lobe memory system.

**Examples:**

- Riding a bicycle.
- Typing without consciously thinking about every movement.
- Recognising a word more quickly after previous exposure.
- Learning a conditioned response.

### **Comparison: Declarative vs. Nondeclarative Memory**

| Dimension           | Declarative Memory           | Nondeclarative Memory                   |
| ------------------- | ---------------------------- | --------------------------------------- |
| Alternative name    | Explicit                     | Implicit                                |
| Awareness           | Conscious recollection       | Does not require conscious recollection |
| Main function       | Remembering facts and events | Skills, habits and learned responses    |
| Includes            | Episodic and semantic        | Skills, habits, priming, conditioning   |
| Major neural system | Medial temporal lobe         | Multiple other neural systems           |
| Amnesia             | Often severely impaired      | Often relatively preserved              |
| Example             | Recalling a birthday         | Riding a bicycle                        |

High-yield NET distinction

**Remember:** Declarative = Knowing that; Nondeclarative = Learning expressed through performance, often described as knowing how.

## **4. Brain Structures Associated with Memory Systems**

Squire's theory is particularly important because it connects memory functions with their underlying neural structures.

### **A. Declarative Memory — Medial Temporal Lobe**

The medial temporal lobe memory system includes:

- Hippocampal formation.
- Entorhinal cortex.
- Perirhinal cortex.
- Parahippocampal cortex.

**Hippocampus:** Particularly important for forming and consolidating new declarative memories.

### **B. Nondeclarative Memory — Different Neural Systems**

| Nondeclarative memory type                    | Important brain structures                  |
| --------------------------------------------- | ------------------------------------------- |
| Skills and habits                             | Basal ganglia / striatum                    |
| Priming                                       | Neocortex                                   |
| Classical conditioning of skeletal responses  | Cerebellum                                  |
| Emotional conditioning                        | Amygdala                                    |
| Simple forms of habituation and sensitisation | Reflex pathways and related neural circuits |

**NET trap:** The hippocampus is particularly associated with declarative memory, not every form of learning and memory.

## **5. Hippocampus and Memory Consolidation**

Squire's research helped establish the importance of the hippocampus in the formation and consolidation of declarative memories.

### **Key concepts**

**1. Memory consolidation**

- The process through which newly formed memories become more stable.
- The hippocampus helps bind together information represented across different cortical areas.
- Over time, some memories become less dependent on the hippocampus.

**2. Temporally graded retrograde amnesia**

- Damage to the hippocampus can produce loss of memories formed before the injury.
- Recent memories are often more vulnerable than remote memories.
- Older memories may remain relatively preserved.

**3. Anterograde amnesia**

- Difficulty forming new long-term memories after brain damage.
- Often associated with damage to the medial temporal lobe memory system.

### **Important distinction**

| Type                                 | Meaning                                                |
| ------------------------------------ | ------------------------------------------------------ |
| Anterograde amnesia                  | Difficulty forming new memories after the injury       |
| Retrograde amnesia                   | Loss of memories formed before the injury              |
| Temporally graded retrograde amnesia | Recent memories are more affected than remote memories |

**NET association:** Squire's consolidation account = Time-limited hippocampal involvement in memory formation and retrieval.

_Important qualification:_ The standard systems-consolidation account proposes that remote memories can become less dependent on the hippocampus. The extent to which richly detailed autobiographical memories remain hippocampus-dependent is debated in other theories.

## **6. Classic Evidence — Patient H.M.**

Although the famous patient H.M. was studied by **Brenda Milner**, his case became central to Squire's account of multiple memory systems.

### **Background**

- Patient H.M. (Henry Molaison) underwent bilateral medial temporal lobe surgery in 1953 to treat severe epilepsy.
- The surgery produced profound anterograde amnesia.
- He had considerable difficulty forming new declarative memories.

### **Important findings**

1. H.M. could not consciously remember newly learned facts and events.
2. His ability to acquire certain motor skills remained relatively intact.
3. He improved in mirror-drawing tasks despite not remembering having performed them previously.

### **Significance**

- Demonstrated that memory is not a single unitary system.
- Showed that declarative memory can be severely impaired while some nondeclarative learning remains intact.
- Provided strong evidence for separate memory systems.

**NET association:** H.M. = Severe anterograde amnesia + preserved motor skill learning.

### **Squire vs. Tulving — Very Important**

- **Tulving:** Divided declarative memory into episodic and semantic memory, while also developing a broader multiple-memory-systems framework.
- **Squire:** Distinguished declarative and nondeclarative memory and connected these systems with different neural structures.

**Relationship between the two classifications**

**Declarative Memory**

Squire's classification

**Episodic**

Personal events

**Semantic**

Facts and knowledge

Tulving's distinction elaborates two major forms of declarative memory in Squire's classification.

## **8. Contributions**

1. Established the importance of distinguishing declarative and nondeclarative memory.
2. Connected memory systems with specific brain structures.
3. Advanced understanding of the hippocampus and medial temporal lobe.
4. Explained why some learning abilities remain intact in amnesia.
5. Integrated findings from human, monkey and rat research.
6. Contributed significantly to cognitive neuroscience and neuropsychology.

## **9. Criticisms and Limitations**

1. **Overlapping systems:** Different memory systems interact, making complete separation difficult.
2. **Complex neural organisation:** Memory functions are distributed across interconnected neural networks rather than isolated brain structures.
3. **Consolidation debate:** The idea that remote memories become entirely independent of the hippocampus is disputed, particularly for detailed autobiographical memories.
4. **Classification limitations:** Some forms of learning do not fit neatly into a single declarative or nondeclarative category.
5. **Consciousness is complex:** The distinction between conscious and nonconscious memory is not always straightforward.
