# **Anne Treisman – Short Revision Notes**

_UGC-NET JRF Psychology — Short Revision Notes_

## **1. Introduction**

- **Anne Treisman (1935–2018):** British cognitive psychologist known for research on attention and visual perception.
- Received her D.Phil. from Oxford in **1962**.
- Worked at Oxford, University of British Columbia, UC Berkeley and Princeton University.
- Received the **National Medal of Science (2013)**.
- Major contributions:
  1. Attenuation Theory (1960).
  2. Feature Integration Theory (1980), with **Gelade**.

**NET keyword:** Treisman = Attenuation + Feature Integration.

## **2. Attenuation Theory (1960)**

- Modified **Broadbent's Filter Model**.
- Unattended information is **weakened (attenuated), not completely blocked**.
- Important information can still receive processing.
- Introduced the concept of **recognition thresholds**.
- Personally significant stimuli, such as one's own name, have a **lower threshold** and can be recognized even when unattended.

**Key distinction:**

- Broadbent → Unattended information is blocked.
- Treisman → Unattended information is weakened.
- Deutsch & Deutsch → All information receives semantic analysis before selection.

## **3. Feature Integration Theory (1980)**

Proposed by **Treisman and Gelade** to explain visual attention and feature binding.

### **Two Stages**

| Preattentive Stage                    | Attentive Stage                |
| ------------------------------------- | ------------------------------ |
| Automatic processing                  | Focused attention              |
| Parallel processing                   | Serial processing              |
| Basic features detected independently | Features combined into objects |
| Fast                                  | Slower                         |
| Pop-out search                        | Conjunction search             |

### **Important Concepts**

**1. Feature Maps**

- Separate maps process features such as colour, shape and orientation.
- Each map represents the location of particular features.

**2. Binding Problem**

- Explains how separately processed features combine into a unified object.
- Attention acts as the **glue** that binds features together.

**3. Illusory Conjunctions**

- Incorrect combination of features when attention is insufficient.
- Example: Perceiving a red circle when the display actually contains a red square and a blue circle.

## **4. Visual Search Paradigm**

| Single Feature Search              | Conjunction Search                  |
| ---------------------------------- | ----------------------------------- |
| One unique feature                 | Combination of features             |
| Parallel processing                | Serial processing                   |
| Fast                               | Slow                                |
| Pop-out effect                     | No typical pop-out                  |
| Relatively independent of set size | Search time increases with set size |

**NET keyword:** The set-size effect in conjunction search supports the role of focused attention in feature binding.

## **5. Comparison with Other Attention Theories**

| Theorist          | Theory                     | Main Idea                                       |
| ----------------- | -------------------------- | ----------------------------------------------- |
| Donald Broadbent  | Filter Model               | Early selection; unattended information blocked |
| Anne Treisman     | Attenuation Theory         | Unattended information weakened                 |
| Treisman & Gelade | Feature Integration Theory | Attention binds visual features                 |
| Deutsch & Deutsch | Late Selection             | Semantic processing before selection            |
| Jeremy Wolfe      | Guided Search Theory       | Attention guided by salient features            |

## **6. Major Contributions**

1. Modified Broadbent's Filter Model.
2. Introduced attenuation and recognition thresholds.
3. Explained visual feature binding.
4. Distinguished pop-out and conjunction searches.
5. Explained illusory conjunctions.
6. Advanced experimental research on visual attention.

## **7. Criticisms**

1. Some single-feature searches require attention.
2. Some conjunction searches can produce pop-out effects.
3. Preattentive processing may not be completely independent.
4. Illusory conjunctions may sometimes involve memory errors.
5. FIT's original framework may not explain every form of visual search.
