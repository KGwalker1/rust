# Carl Gustav Jung – Analytical Psychology

## 1. Introduction and Basic Concepts

| Topic             | Key Points for Memory                                                         |
| ----------------- | ----------------------------------------------------------------------------- |
| Lifespan          | 1875–1961                                                                     |
| School            | Analytical Psychology                                                         |
| Break with Freud  | 1913                                                                          |
| Main disagreement | Nature of libido; Freud emphasised sexuality, Jung generalised psychic energy |
| Libido            | Generalised psychic/life energy                                               |
| Main goal of life | Individuation                                                                 |
| Personality       | Dynamic, holistic and self-regulating                                         |
| Development       | Lifelong; midlife is especially important                                     |

## 2. Structure of the Psyche

| Component              | Key Points                                                          |
| ---------------------- | ------------------------------------------------------------------- |
| Ego                    | Centre of consciousness; identity and awareness                     |
| Personal unconscious   | Forgotten, repressed and ignored personal experiences               |
| Collective unconscious | Universal, inherited layer shared by humanity                       |
| Complexes              | Emotionally charged clusters in the personal unconscious            |
| Archetypes             | Universal innate patterns originating in the collective unconscious |
| Self                   | Centre and totality of the psyche; symbolised by the mandala        |

## 3. Major Archetypes

| Archetype        | Key Points                                             |
| ---------------- | ------------------------------------------------------ |
| Persona          | Social mask or public face                             |
| Shadow           | Unacknowledged or rejected aspects of personality      |
| Anima            | Feminine aspect in the male psyche                     |
| Animus           | Masculine aspect in the female psyche                  |
| Self             | Wholeness and integration of conscious and unconscious |
| Other archetypes | Great Mother, Hero, Wise Old Man, Child, Trickster     |

## 4. Psychological Types

| Concept              | Key Points                                          |
| -------------------- | --------------------------------------------------- |
| Extraversion         | Psychic energy directed outward                     |
| Introversion         | Psychic energy directed inward                      |
| Thinking             | Logical evaluation                                  |
| Feeling              | Evaluation of worth or value; a rational function   |
| Sensation            | Perception of what exists through the senses        |
| Intuition            | Perception of possibilities and underlying patterns |
| Rational functions   | Thinking and Feeling                                |
| Irrational functions | Sensation and Intuition                             |
| Eight types          | Two attitudes × four dominant functions             |
| Publication          | Psychological Types (1921)                          |
| Influence            | Myers–Briggs Type Indicator (MBTI)                  |

## 5. Development and Individuation

| Topic                 | Key Points                                                         |
| --------------------- | ------------------------------------------------------------------ |
| Childhood             | Gradual development of the ego                                     |
| Youth                 | Adaptation to the external world; career, marriage and achievement |
| Midlife               | Around 35–40 onwards; turning inward and searching for meaning     |
| Old age               | Continued individuation and reflection on mortality                |
| Individuation         | Lifelong process of becoming a whole, unique self                  |
| Stages of integration | Persona → Shadow → Anima/Animus → Self                             |
| Midlife crisis        | Reassessment of goals, values and meaning                          |

## 6. Psychic Dynamics and Energy

| Concept                  | Key Points                                                                 |
| ------------------------ | -------------------------------------------------------------------------- |
| Principle of equivalence | Energy withdrawn from one psychic element is transferred elsewhere         |
| Principle of entropy     | Psychic energy tends towards balance                                       |
| Progression              | Adaptation to the external world                                           |
| Regression               | Withdrawal or movement back towards inner processes                        |
| Compensation             | Unconscious balances one-sided conscious attitudes                         |
| Transcendent function    | Reconciliation of opposing psychic forces through a new symbol or position |

## 7. Dreams and Assessment

| Topic                 | Key Points                                                 |
| --------------------- | ---------------------------------------------------------- |
| Dreams                | Compensatory and prospective                               |
| Dream interpretation  | Objective and subjective levels                            |
| Amplification         | Interpretation using myths, symbols and cultural parallels |
| Active imagination    | Conscious dialogue with unconscious images                 |
| Word Association Test | Used to identify emotionally charged complexes             |
| Early recollections   | More strongly associated with Adler's approach             |

## 8. Psychopathology and Therapy

| Topic                    | Key Points                                                             |
| ------------------------ | ---------------------------------------------------------------------- |
| Neurosis                 | Conflict between conscious attitudes and the unconscious               |
| Symptoms                 | May signal psychological imbalance                                     |
| Therapeutic goal         | Integration, balance and individuation                                 |
| Techniques               | Dream analysis, amplification, active imagination and word association |
| Therapeutic relationship | Mutual influence and transformation                                    |

## 9. Other Important Concepts

| Concept        | Key Points                                                                             |
| -------------- | -------------------------------------------------------------------------------------- |
| Synchronicity  | Meaningful coincidence without a direct causal connection                              |
| Wolfgang Pauli | Physicist associated with Jung's work on synchronicity                                 |
| Mandala        | Symbol of the Self and psychic wholeness                                               |
| Influence      | Analytical therapy, typology, transpersonal psychology and popular archetypal analysis |

## 10. Contributions and Criticisms

| Contributions                            | Criticisms                               |
| ---------------------------------------- | ---------------------------------------- |
| Collective unconscious and archetypes    | Difficult to test empirically            |
| Lifespan development and individuation   | Mysticism and occult influences          |
| Psychological types                      | Rigid gender assumptions in anima/animus |
| Word Association Test and complex theory | Vague and diffuse theoretical writing    |
| Emphasis on meaning and spirituality     | Universal archetype claims are debated   |
