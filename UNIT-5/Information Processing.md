# **Information Processing Approach to Perception**

An exam-oriented short note for **UGC-NET JRF Psychology (December 2026)**.

## **1. Introduction**

The **Information Processing Approach** explains perception as an active process in which sensory information is received, transformed, organized, interpreted and stored by the brain.

- It compares the human mind to an information-processing system.
- Sensory information enters through sensory receptors and is processed by the nervous system.
- Perception involves several stages, including sensation, attention, recognition, interpretation and memory.
- It emphasizes the interaction between bottom-up and top-down processing.

**Central idea:** Perception is not simply the recording of sensory information; it involves the active processing and interpretation of information.

## **2. Stages of Information Processing in Perception**

The process can be understood through the following stages:

1. **Sensory input:** Information from the environment is received through sensory receptors.
2. **Sensory registration:** Sensory information is briefly maintained in sensory memory.
3. **Attention:** Relevant information is selected for further processing.
4. **Feature extraction:** Important features such as colour, shape, size, orientation and movement are identified.
5. **Pattern recognition:** Extracted features are organized into meaningful patterns and objects.
6. **Interpretation:** The brain assigns meaning to the perceived information using previous knowledge and experience.
7. **Memory storage:** Processed information may be stored in long-term memory for future use.

Simplified sequence: Sensory input → Sensory registration → Attention → Feature extraction → Pattern recognition → Interpretation → Memory.

## **3. Two Major Types of Information Processing**

### **A. Bottom-Up Processing (Data-Driven Processing)**

- Begins with sensory information received from the environment.
- Perception develops from basic sensory features towards meaningful recognition.
- Does not initially depend on expectations or previous knowledge.
- Associated with the work of James J. Gibson and other theorists of direct perception.

**Example:** Identifying an unfamiliar object by examining its shape, colour and texture.

### **B. Top-Down Processing (Conceptually Driven Processing)**

- Perception is influenced by prior knowledge, expectations, beliefs, experiences and context.
- The brain uses existing information to interpret incoming sensory information.
- Associated with the work of Richard Gregory.

**Example:** Reading a word despite missing letters because the surrounding sentence provides contextual clues.

### **Bottom-Up vs Top-Down Processing**

| Bottom-up processing                                 | Top-down processing                                      |
| ---------------------------------------------------- | -------------------------------------------------------- |
| Data-driven                                          | Conceptually driven                                      |
| Begins with sensory input                            | Begins with expectations and prior knowledge             |
| Proceeds from simple features to complex recognition | Uses existing knowledge to interpret sensory information |
| Stimulus-based                                       | Knowledge-based                                          |
| Example: Identifying an object through its features  | Example: Recognizing an unclear word using context       |

**NET point:** Normal perception generally involves an interaction between bottom-up and top-down processing.

## **4. Important Models and Theories**

### **A. David Marr's Computational Theory of Vision (1982)**

David Marr proposed that visual perception involves multiple levels of information processing.

He identified three important levels:

1. **Computational theory:** Explains what information-processing problem the visual system is solving and why.
2. **Representation and algorithm:** Explains how information is represented and what processes are used to transform it.
3. **Hardware implementation:** Explains how the processing is physically implemented in the brain and nervous system.

**Three stages of visual representation:**

| Stage                        | Explanation                                                                            |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| **Primal sketch**            | Represents basic visual features such as edges, bars, boundaries and intensity changes |
| **2½-D sketch**              | Represents surface orientation, depth and spatial arrangement relative to the observer |
| **3-D model representation** | Represents objects in a three-dimensional, object-centred form                         |

Important: Marr's three stages describe visual representations, while his three levels explain computational analysis. Do not confuse them.

### **B. Feature Integration Theory – Anne Treisman and Garry Gelade (1980)**

- Explains how individual visual features are combined to form a unified perception of objects.
- Visual processing involves two major stages:

**1. Preattentive stage**

- Basic features such as colour, orientation and size are processed rapidly and automatically.
- Attention is not required to detect certain basic features.

**2. Focused attention stage**

- Attention combines separate features into a unified object representation.
- This process helps prevent illusory conjunctions, where features from different objects are incorrectly combined.

**Example:** Identifying a red circle among blue circles and red squares.

### **C. Recognition-by-Components Theory – Irving Biederman (1987)**

- Explains object recognition through basic geometric components called **geons**.
- Objects are recognized by identifying their component shapes and structural relationships.
- Biederman proposed approximately 36 basic geons.
- Geons include basic shapes such as cylinders, cones and blocks.

**Example:** Recognizing a table through its basic components and their arrangement.

### **D. Information Processing and Pattern Recognition**

Pattern recognition refers to identifying and interpreting sensory patterns as meaningful objects.

Important approaches include:

- **Template matching:** Comparing incoming sensory information with stored templates.
- **Feature analysis:** Identifying distinctive features of stimuli.
- **Prototype matching:** Comparing stimuli with an ideal or average representation.
- **Structural description:** Recognizing objects through their component parts and spatial relationships.

## **5. Role of Attention and Memory**

**Attention**

- Selects relevant sensory information for further processing.
- Prevents excessive processing of irrelevant information.
- Influences which stimuli reach conscious awareness.

**Memory**

- Provides stored knowledge and previous experiences.
- Helps recognize familiar objects and patterns.
- Supports top-down processing by supplying expectations and contextual information.

## **6. Important Characteristics of the Information Processing Approach**

1. **Active processing:** The mind actively transforms sensory information.
2. **Sequential processing:** Information can pass through different processing stages.
3. **Parallel processing:** Some information can be processed simultaneously.
4. **Limited capacity:** Attention and cognitive resources are limited.
5. **Selective processing:** Relevant information receives priority.
6. **Interaction of processes:** Sensory input, attention, memory and expectations interact during perception.

## **8. Important NET/JRF Points**

- **Bottom-up processing:** Data-driven, begins with sensory input.
- **Top-down processing:** Conceptually driven, influenced by prior knowledge.
- **Marr:** Primal sketch → 2½-D sketch → 3-D model representation.
- **Treisman and Gelade:** Preattentive processing and focused attention.
- **Biederman:** Geons and object recognition.
- **Template matching:** Recognition through comparison with stored templates.
- **Feature analysis:** Recognition through distinctive stimulus features.
- **Parallel processing:** Multiple aspects of information can be processed simultaneously.
- **Serial processing:** Information is processed in a sequence.

**Central idea:** The information processing approach views perception as a series of active cognitive operations involving sensory input, attention, feature extraction, pattern recognition, interpretation and memory. It explains how the brain transforms raw sensory information into meaningful experiences.
