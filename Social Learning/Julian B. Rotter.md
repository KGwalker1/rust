# Julian B. Rotter – Social Learning Theory

## 1. Introduction and Basic Concepts

| Topic           | Key Points for Memory                                        |
| --------------- | ------------------------------------------------------------ |
| Lifespan        | 1916–2014                                                    |
| Theory          | Social Learning Theory of Personality                        |
| Landmark book   | Social Learning and Clinical Psychology (1954)               |
| Major influence | Kurt Lewin, Clark Hull, Edward Tolman, Alfred Adler          |
| Core principle  | Behaviour = function of person and environment               |
| Formula         | \\(B=f(P,E)\\)                                               |
| Main emphasis   | Expectancy, reinforcement, goals and psychological situation |
| Approach        | Scientific, predictive and testable                          |

## 2. Major Constructs

| Concept                  | Key Points                                                       |
| ------------------------ | ---------------------------------------------------------------- |
| Behaviour Potential (BP) | Probability of a behaviour occurring in a situation              |
| Expectancy (E)           | Subjective probability that behaviour will lead to reinforcement |
| Specific expectancy      | Expectation in a particular situation                            |
| Generalised expectancy   | Belief influencing behaviour across situations                   |
| Reinforcement Value (RV) | Preference for one reinforcement over alternatives               |
| Core formula             | \\(BP=f(E\times RV)\\)                                           |
| Psychological situation  | Situation as perceived and interpreted by the individual         |
| Minimal goal level       | Lowest acceptable outcome before dissatisfaction                 |
| Need Potential (NP)      | Likelihood of performing behaviours directed towards a goal      |
| Freedom of movement      | Expectancy of obtaining reinforcement in a need area             |
| Need Value               | Value attached to reinforcement related to a need                |

## 3. Locus of Control

| Topic          | Key Points                                                      |
| -------------- | --------------------------------------------------------------- |
| Definition     | Generalised expectancy about control over reinforcement         |
| Internal locus | Outcomes depend mainly on one's actions, ability and effort     |
| External locus | Outcomes depend mainly on luck, fate, chance or powerful others |
| Nature         | Continuum, not a strict dichotomy                               |
| Development    | Learned through experience and socialisation                    |
| Scale          | Rotter's Internal–External (I–E) Scale                          |
| Year           | 1966                                                            |
| Scale format   | 29 forced-choice items: 23 scored + 6 fillers                   |
| High I–E score | More external locus of control                                  |

## 4. Internal vs External Locus of Control

| Domain      | Internal Locus                     | External Locus                                |
| ----------- | ---------------------------------- | --------------------------------------------- |
| Achievement | Emphasises effort and persistence  | May attribute outcomes to luck                |
| Information | Actively seeks information         | May rely more on external cues                |
| Persuasion  | More influenced by message content | May be more influenced by authority or status |
| Health      | Often takes preventive action      | May feel less personal control                |
| Gambling    | Prefers skill-based activities     | May rely more on chance                       |
| Motivation  | Mastery and achievement            | Social rewards and approval                   |

These are general tendencies, not fixed characteristics of every individual.

## 5. Interpersonal Trust

| Topic                     | Key Points                                                  |
| ------------------------- | ----------------------------------------------------------- |
| Interpersonal Trust Scale | Developed by Rotter                                         |
| Year                      | 1967                                                        |
| Measures                  | Generalised expectation that others are honest and reliable |
| Low trust                 | Suspiciousness and difficulty trusting others               |

## 6. Maladjustment and Therapy

| Topic                    | Key Points                                                           |
| ------------------------ | -------------------------------------------------------------------- |
| Causes of maladjustment  | Unrealistic expectancies, conflicting goals and skill deficits       |
| Symptoms                 | May serve a goal-directed function, such as avoiding feared outcomes |
| Therapeutic goal         | Change behaviour by changing expectancies and values                 |
| Therapeutic relationship | Warm, trusting and reinforcing                                       |
| Techniques               | Role-playing, graded exposure, modelling and behavioural rehearsal   |
| Focus                    | Present goals, expectations and competencies                         |

## 7. Assessment Techniques

| Test / Technique                         | Key Points                                       |
| ---------------------------------------- | ------------------------------------------------ |
| I–E Scale (1966)                         | Measures locus of control                        |
| Interpersonal Trust Scale (1967)         | Measures interpersonal trust                     |
| Rotter Incomplete Sentences Blank (RISB) | Developed in 1950; sentence-completion technique |
| RISB purpose                             | Assesses adjustment and maladjustment            |

## 8. Comparison with Other Theorists

| Theorist       | Key Concept                                              |
| -------------- | -------------------------------------------------------- |
| B. F. Skinner  | Operant conditioning and reinforcement                   |
| Julian Rotter  | Expectancy, reinforcement value and locus of control     |
| Albert Bandura | Observational learning, modelling and self-efficacy      |
| Walter Mischel | Cognitive-affective personality system (CAPS)            |
| Kurt Lewin     | Field theory; \\(B=f(P,E)\\)                             |
| Bernard Weiner | Attribution theory: locus, stability and controllability |

## 9. Contributions and Criticisms

| Contributions                                       | Criticisms                                                     |
| --------------------------------------------------- | -------------------------------------------------------------- |
| Bridged behaviourism and cognitive theory           | Some constructs are abstract                                   |
| Developed locus of control as a major construct     | I–E Scale may overlook domain-specific differences             |
| Emphasised person–environment interaction           | External control can be realistic in uncontrollable situations |
| Promoted predictive and testable personality theory | May underemphasise biological and unconscious factors          |
| Influenced clinical and health psychology           | Internal locus may reflect Western cultural values             |
