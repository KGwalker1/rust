## **1. Introduction**

- **Feature Integration Theory (FIT)** was proposed by **Anne Treisman and Garry Gelade (1980)**.
- It explains how attention helps combine separate visual features into a unified object.
- According to the theory, visual perception occurs in two stages:
  1. Preattentive stage.
  2. Focused attention stage.
- Attention is essential for correctly combining different features such as colour, shape, size and orientation.

**Central assumption:** Basic visual features are processed separately, but focused attention binds them together to form a complete object.

### **A. Preattentive Stage**

- Occurs automatically and rapidly.
- Does not require focused attention.
- Basic visual features are processed separately.
- Features include:
  - Colour
  - Shape
  - Size
  - Orientation
  - Movement
- Processing occurs in parallel across the visual field.

**Example:** A red object among several blue objects can be detected quickly.

### **B. Focused Attention Stage**

- Requires selective attention.
- Different visual features are combined or integrated.
- Attention moves across objects to create a unified perception.
- This process is generally serial, particularly when searching for a conjunction of features.

**Example:** Identifying a red triangle among red circles and blue triangles requires combining colour and shape.

## **3. Feature Maps and Master Map of Locations**

Treisman proposed two important representations:

| Component               | Function                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------ |
| Feature Maps            | Process individual visual features separately, such as colour, shape and orientation |
| Master Map of Locations | Represents the spatial locations of visual features and helps direct attention       |

- During focused attention, attention selects a location on the master map.
- Features at that location are combined into a unified object representation.
- This process is known as **feature binding**.

## **4. Illusory Conjunctions**

- An **illusory conjunction** occurs when features from different objects are incorrectly combined.
- It is more likely when attention is limited or distracted.
- It supports the idea that focused attention is necessary for accurate feature binding.

**Example:**

Imagine seeing:

- A red X.
- A blue O.

Under conditions of insufficient attention, a person may incorrectly report seeing a red O or blue X.

## **5. Visual Search and Feature Integration Theory**

Treisman used visual search experiments to examine how attention operates.

| Type of search     | Characteristics                                                                        |
| ------------------ | -------------------------------------------------------------------------------------- |
| Feature Search     | Target differs from distractors by one basic feature; usually rapid and parallel       |
| Conjunction Search | Target is defined by a combination of features; usually slower and attention-demanding |

**Example:**

- Feature search: Finding a red circle among blue circles.
- Conjunction search: Finding a red circle among red squares and blue circles.

### **Search Slopes**

- Feature search: Usually produces a relatively flat reaction-time slope as the number of distractors increases.
- Conjunction search: Usually produces a steeper slope because attention must inspect and combine features.

## **6. Important Experiment (1980)**

**Treisman and Gelade (1980)** conducted visual search experiments.

Major findings:

- Single-feature targets were detected rapidly.
- Conjunction targets required more time.
- Illusory conjunctions occurred when attention was inadequate.

These findings supported the two-stage model of visual attention.

## **7. Limitations and Criticism**

- Some conjunction searches can occur efficiently and in parallel.
- Some single-feature searches are not always effortless.
- Search efficiency also depends on practice, target-distractor similarity and perceptual grouping.
- The strict distinction between parallel and serial processing is not sufficient to explain every visual-search task.
